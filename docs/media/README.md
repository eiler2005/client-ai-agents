# Оформление главной страницы

Здесь хранятся оригинальные материалы оформления README общей базы.
`assess build` не создаёт и не изменяет их. Сгенерированные фигуры отчётов
остаются в отдельном `docs/assets/` и не коммитятся.

| Файл | Назначение |
|---|---|
| [readme-hero.png](readme-hero.png) | Готовая обложка 1774×887, соотношение сторон 2:1 |
| [readme-hero-prompt.md](readme-hero-prompt.md) | Точный промпт для повторной генерации |

Иллюстрация показывает переход от запроса клиента через проектирование решения
к материалам проекта. Бумажные страницы и схема — вымышленная композиция;
они не изображают клиентское решение, работающий интерфейс или результаты оценки.
Клиентские документы, фотографии и референсные презентации в генерацию
не передавались. Обложка просмотрена перед публикацией.

Оформление следует рабочей палитре Cinimex Consulting: тёмно-синий фон,
светлые поверхности и оранжевый акцент. Палитра отделена от управленческой логики
в [стилевых настройках](../../skills/consulting-presentations/assets/styles/cinimex.json).
Это рабочий стиль проекта, а не опубликованный корпоративный брендбук.

Обложка создана встроенным инструментом генерации изображений 7 октября
2026 года. Структура и текст README подготовлены с рецензией Astra.
Исходное разрешение сохранено без увеличения; при ширине README около 850 px
изображение имеет более двух исходных пикселей на экранный пиксель.
Все названия, ссылки и пояснения остаются редактируемым текстом Markdown.
