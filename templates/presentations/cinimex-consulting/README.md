# Cinimex Consulting

Отдельный стиль, выбранный 6 октября 2026. Тёмная обложка, светлая аналитика,
крупная типографика, фирменный оранжевый и настоящий логотип Синимекс.

В v2 закреплено правило обложки: иллюстрация должна объяснять конкретный проект.
Для подбора оборудования это принтер, каталог и чат; для другого проекта агент
выбирает собственный предметный визуал. Универсальные круги с AI — часть старого
эталона v1; в клиентской обложке их заменяем. Название проекта, заказчик,
предложение Синимекс и контакты из профиля остаются редактируемым текстом.

Расширение [«Схемы и решения»](../../../docs/PRESENTATION_VISUAL_STANDARD.md)
**принято 7 октября 2026 года** как стандарт проекта и конвейер подготовки. Оно основано на исследовании
пяти просмотренных официальных фигур McKinsey, Bain, BCG и Accenture, сохраняет
нашу палитру и шрифты. Для новой или изменяемой презентации обязательна
последовательность: содержание → факты → история → смысл схем → сборка →
проверка текста и всех слайдов → передача с манифестом. Для каждой стадии в
стандарте указаны результат и условие перехода. PDF по умолчанию не требуется.

`style.yaml` описывает палитру и композиции. `template.json` хранит два слайда как
редактируемые объекты artifact-tool: текст, геометрию и заметки. Логотип находится
в отдельном `logo.svg`; встроенных двоичных данных в JSON нет. Содержание эталона —
объяснение нашей методики, без клиентских данных. Заменять его реальной оценкой
в этом каталоге нельзя: клиентский материал остаётся вне git.

Сборка эталона:

```sh
node templates/presentations/cinimex-consulting/render.mjs
# или указать путь итогового PPTX:
node templates/presentations/cinimex-consulting/render.mjs dist/slides/my-reference.pptx
```

Нужны Node.js 22+ и `@oai/artifact-tool` из среды Codex; другой каталог пакета
задаётся `CINIMEX_ARTIFACT_TOOL`. PPTX попадает в игнорируемый `dist/slides/`,
превью — во временную папку ОС. Внешний исходный PPTX больше не требуется.

Для новой презентации указывать агенту: «Используй стиль `cinimex-consulting`
из `templates/presentations/cinimex-consulting/`; клонируй нужные композиции,
сохрани редактируемый текст». Обложка подходит для начала истории;
второй слайд — для трёх условий, направлений или вариантов. Композицию выбирать
по вопросу клиента: путь запроса, архитектура, источник и проверка ответа,
сравнение или этапы. Длинный материал разделять, сохраняя размер шрифта,
основания и ограничения для самостоятельного чтения.

Для презентаций с развёрнутым текстом [render-reading.mjs](render-reading.mjs)
добавляет к клонированному эталону содержание, резюме для руководства, вводные
слайды частей, таблицы, крупные схемы и этапы с условиями перехода. Содержание
связывается с диапазонами слайдов; понимание задачи отделяется от предложения
по её решению. Конвейер [build_reading_deck.py](../../../scripts/build_reading_deck.py)
готовит данные профиля, клонирует слайды, сохраняет превью и сверяет весь текст
PPTX с исходником. Команда сборки — в
[стандарте презентаций](../../../docs/PRESENTATION.md); материалы конкретного
клиента находятся в его локальной папке `clients/<client-id>/`.
Нужен установленный скилл Presentations; исходные изображения указываются
отдельными путями и сохраняются вместе с локальными артефактами.

Для читаемой колоды также доступны предметное сравнение двух сценариев,
сопоставление способов поиска, образец подбора с пояснениями, поля каталога,
основания фрагментов ответа, сравнение размещения, дерево проверки ценности
и контрастные примеры приёмки. Их `visual_copy` — клиентский текст, который
проверяется при извлечении наравне с абзацами. Не использовать иллюстративные
статусы или варианты как результат обследования реального каталога.

`assess slides` пока
использует свой автоматический макет из `src/content/presentation.yaml`;
флаг выбора этого шаблона для всей оценки не добавлен. JSON-конвейер описан
отдельно и не меняет существующий формат YAML оценок и КП.

Источник композиции — пользовательский `Digital_Ruble_Explainer_RU_v3.pptx`,
слайды 1–2, адаптированные по просьбе пользователя. Это собственный стиль Синимекс.
Исследование консультантов и направления развития находятся в
[PRESENTATION_RESEARCH.md](../../../docs/PRESENTATION_RESEARCH.md) и
[PRESENTATION_VISUAL_RESEARCH.md](../../../docs/PRESENTATION_VISUAL_RESEARCH.md).
