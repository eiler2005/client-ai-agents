# Локальные исходные примеры

`slides-examples/` — локальная копия пользовательской папки
`~/Downloads/slides examples/`. Оригиналы в Downloads сохраняются.
Вся вложенная папка исключена из Git и защищена хуками, включая извлечённый текст
и реестры разбора. В общий репозиторий входит только эта инструкция.

| Локальный путь | Содержание |
|---|---|
| `slides-examples/originals/` | Неизменённые PDF/PPTX; контрольные суммы сверяются с исходниками |
| `slides-examples/manifest.json` | Перечень файлов, количество страниц/слайдов, хеши, покрытие просмотра |
| `slides-examples/derived/` | Полные PNG каждой страницы, извлечённый текст PDF и исходный XML слайдов |
| `slides-examples/reviews/` | Постраничные наблюдения: управление, визуальные отношения, повторы и ограничения |

Разбор 7 октября 2026: пять файлов, 60 страниц PDF и 76 слайдов PPTX.
Все 136 изображений просмотрены индивидуально. PDF рендерились через Poppler;
PPTX — через импорт artifact-tool. Нативный PowerPoint не открывался; ограничения
импорта фиксируются отдельно от наблюдений об исходном оформлении.

Для нового поступления сначала обнови перечень и количество страниц, затем
постраничное покрытие. Контактный лист помогает навигации, но не заменяет чтение.
В [общую библиотеку](../skills/consulting-presentations/SKILL.md) добавляются только
абстрактные M/V-рецепты и собственные вымышленные образцы. Клиентские данные,
архитектура, внутренние ссылки и копии изображений остаются здесь локально.
